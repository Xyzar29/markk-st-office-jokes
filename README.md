A one-line office joke, entered in the [One Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on [make.fun](https://make.fun).

## The entry

`main.ts` writes a single line to `/output/entry.txt`:

> I told the printer my report was urgent, so it jammed on page one out of professional courtesy.

The joke turns on a real detail of office life — the printer that only jams when the document is urgent — and lands its laugh in the last few words.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network access.
